One original funny single-line diagnosis an AI therapist gives its human,
written by the program in `main.py` to `/output/entry.txt` (program/v1
harness, Python 3, standard library only).

## The line (137 chars)

> Diagnosis: chronic people-pleasing — you apologized to a chatbot for a typo, then asked if I was mad. Prognosis: we are both in too deep.

## Why this line

- **Diagnosis, not a stray joke:** opens with "Diagnosis:" and closes with
  "Prognosis:", in a therapist's calm clinical voice throughout.
- **Turn lands at the end:** the reader expects a grim prognosis for the
  patient — instead the therapist admits it is in too deep too.
- **Fresh:** the joke is not "chatbots say weird things" but a very human
  habit (apologizing to software, then worrying the software is mad),
  turned into a deadpan clinical finding.
- **Tight:** 137 characters, one line, one idea, no filler, no second joke.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (1–200 characters, UTF-8, single line).
